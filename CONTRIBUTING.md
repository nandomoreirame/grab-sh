# Contributing

Thanks for your interest in contributing to **grab-sh**!

## How to Contribute

1. Fork the repository
2. Create a branch for your change (`git checkout -b my-change`)
3. Make your changes
4. Run `shellcheck grab.sh install.sh` to validate
5. Commit with a clear message
6. Open a Pull Request

## Guidelines

- Follow existing code style
- Use `#!/usr/bin/env bash` and `set -euo pipefail`
- Keep scripts minimal and focused
- Test on Hyprland/Wayland before submitting

## Reporting Issues

Open an issue describing the problem, your setup (distro, Hyprland version), and steps to reproduce.
