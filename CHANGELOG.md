## [0.1.0] - 2026-03-31

### Added

- Unified `grab.sh` script with `full` and `area` subcommands for screenshot capture to clipboard
- Window picker for `grab full` using Hyprland active workspace filtering
- Area selection for `grab area` via slurp crosshair
- `install.sh` with dependency checking, symlink creation, and idempotent execution
- `--help` flag with usage info and suggested Hyprland keybindings
